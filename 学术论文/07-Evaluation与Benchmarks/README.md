# Agent Evaluation、Benchmark 与真实工作任务

关注 Agent 到底有没有完成任务、是否可靠、工具是否正确、长流程是否稳定，以及如何在接近真实工作的环境中评估。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。

| # | 论文 | ID | 年份 | 与本项目的关联 |
|---:|---|---|---:|---|
| 1 | [AgentBench: Evaluating LLMs as Agents](https://arxiv.org/abs/2308.03688) | 2308.03688 | 2023 | 经典 Agent benchmark，覆盖多种交互式环境。 |
| 2 | [GAIA: a benchmark for General AI Assistants](https://arxiv.org/abs/2311.12983) | 2311.12983 | 2023 | 面向通用 AI Assistant 的综合任务基准，强调工具与多步推理。 |
| 3 | [WebArena: A Realistic Web Environment for Building Autonomous Agents](https://arxiv.org/abs/2307.13854) | 2307.13854 | 2023 | 在接近真实网站环境里测试 Agent 完成任务的能力。 |
| 4 | [AgentGym: Evolving Large Language Model-based Agents across Diverse Environments](https://arxiv.org/abs/2406.04151) | 2406.04151 | 2024 | 提供多环境 Agent 学习与评估框架。 |
| 5 | [ToolSandbox: A Stateful, Conversational, Interactive Evaluation Benchmark for LLM Tool Use Capabilities](https://arxiv.org/abs/2408.04682) | 2408.04682 | 2024 | 专门评估有状态、多轮 Tool Use。 |
| 6 | [τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains](https://arxiv.org/abs/2406.12045) | 2406.12045 | 2024 | 把真实世界领域中的用户、工具、Agent 三方交互纳入评估。 |
| 7 | [WorkArena: How Capable Are Web Agents at Solving Common Knowledge Work Tasks?](https://arxiv.org/abs/2403.07718) | 2403.07718 | 2024 | 直接面向企业常见知识工作任务，和 Enterprise Agent 场景高度相关。 |
