# Context Engineering、长上下文与上下文管理

关注 Agent 在单轮、多轮、长任务中究竟把什么信息放进模型当前上下文，以及如何压缩、折叠、淘汰和重新组合上下文。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。

| # | 论文 | ID | 年份 | 与本项目的关联 |
|---:|---|---|---:|---|
| 1 | [Context as a Tool: Context Management for Long-Horizon SWE-Agents](https://arxiv.org/abs/2512.22087) | 2512.22087 | 2025 | 把 context management 本身提升成 Agent 可调用/可控制的工具。 |
| 2 | [ACON: Optimizing Context Compression for Long-horizon LLM Agents](https://arxiv.org/abs/2510.00615) | 2510.00615 | 2025 | 研究长任务中的 context compression 策略与效率。 |
| 3 | [Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models](https://arxiv.org/abs/2510.04618) | 2510.04618 | 2025 | 把上下文视为可演化对象，而不是固定 prompt。 |
| 4 | [Scaling Long-Horizon LLM Agent via Context-Folding](https://arxiv.org/abs/2510.11967) | 2510.11967 | 2025 | 研究通过 context folding 保持长周期任务的有效信息。 |

| 6 | [Beyond Compaction: Structured Context Eviction for Long-Horizon Agents](https://arxiv.org/abs/2606.11213) | 2606.11213 | 2026 | 研究结构化地淘汰上下文，而不只是简单摘要压缩。 |
