# RAG、检索与知识增强

关注 Agent 如何从外部语料获取事实：Dense Retrieval、Retrieval-Augmented Generation、检索后生成、反思式检索以及层次化检索。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。

| # | 论文 | ID | 年份 | 与本项目的关联 |
|---:|---|---|---:|---|
| 1 | [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401) | 2005.11401 | 2020 | RAG 基础论文；定义非参数知识检索 + 生成的经典范式。 |
| 2 | [REALM: Retrieval-Augmented Language Model Pre-Training](https://arxiv.org/abs/2002.08909) | 2002.08909 | 2020 | 把外部知识检索引入语言模型预训练，是现代 RAG 的重要前置工作。 |
| 3 | [Improving language models by retrieving from trillions of tokens](https://arxiv.org/abs/2112.04426) | 2112.04426 | 2021 | RETRO 代表大规模检索式语言模型，说明外部记忆可以扩展模型参数知识。 |
| 4 | [Dense Passage Retrieval for Open-Domain Question Answering](https://arxiv.org/abs/2004.04906) | 2004.04906 | 2020 | DPR 是现代 dense retrieval 的经典基线，对知识库检索层设计影响很大。 |
| 5 | [Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection](https://arxiv.org/abs/2310.11511) | 2310.11511 | 2023 | 把是否检索、如何检索、如何检查证据纳入生成过程。 |
| 6 | [RAPTOR: Recursive Abstractive Processing for Tree-Organized Retrieval](https://arxiv.org/abs/2401.18059) | 2401.18059 | 2024 | 用递归摘要树解决长文档、多粒度信息检索问题。 |
| 7 | [Retrieval-Augmented Generation for Large Language Models: A Survey](https://arxiv.org/abs/2312.10997) | 2312.10997 | 2023 | 系统梳理 RAG 架构、训练、检索、增强与评估。 |
