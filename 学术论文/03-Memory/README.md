# Agent Memory：长期记忆、情景记忆与语义记忆

关注 Agent 如何保存经历、事实、偏好、关系和过去任务结果，以及如何在长期运行中选择、压缩、更新和检索这些信息。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。
