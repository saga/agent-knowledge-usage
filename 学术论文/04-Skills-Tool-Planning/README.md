# Skills、Tool Use、Planning 与 Procedural Knowledge

关注怎么完成一类事情：工具调用、计划、动作、程序性知识、可复用技能以及从经验中形成执行能力。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。
