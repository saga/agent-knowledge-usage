# 知识图谱、本体与结构化业务知识

关注知识是什么、概念如何关联、关系如何约束，以及 LLM 与 KG / ontology 的结合。它与企业 Business Knowledge、Semantic Layer 最接近。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。

| # | 论文 | ID | 年份 | 与本项目的关联 |
|---:|---|---|---:|---|
| 1 | [Unifying Large Language Models and Knowledge Graphs: A Roadmap](https://arxiv.org/abs/2306.08302) | 2306.08302 | 2023 | 提出 LLM + KG 的统一研究路线，适合作为总体框架入口。 |
| 2 | [Enhancing Knowledge Graph Construction Using Large Language Models](https://arxiv.org/abs/2305.04676) | 2305.04676 | 2023 | 研究如何利用 LLM 自动构建/补全知识图谱，连接文档知识与结构化知识。 |
| 3 | [Combining Knowledge Graphs and Large Language Models](https://arxiv.org/abs/2407.06564) | 2407.06564 | 2024 | 综述 KG 与 LLM 的互补方式，覆盖知识注入、推理、生成等。 |
| 4 | [Thinking with Knowledge Graphs: Enhancing LLM Reasoning Through Structured Data](https://arxiv.org/abs/2412.10654) | 2412.10654 | 2024 | 研究让 LLM 借助 KG 进行结构化推理，直接关联企业关系、实体和约束。 |

| 7 | [Construct, Align, and Reason: Large Ontology Models for Enterprise Knowledge Management](https://arxiv.org/abs/2602.00029) | 2602.00029 | 2026 | 直接面向 Enterprise Knowledge Management 的 ontology 模型，和企业业务语义层高度相关。 |
