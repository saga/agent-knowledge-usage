# Agent Safety、Governance 与 Enterprise Reliability

关注企业 Agent 的安全边界、风险、权限、治理、可靠性和运行时控制。与金融服务场景尤其相关。

> 说明：本目录以 arXiv 等公开预印本为主；年份按首次公开年份整理。论文是否经过同行评审需以论文正式发表信息为准。
