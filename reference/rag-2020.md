# Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Source: https://arxiv.org/abs/2005.11401
Publication: NeurIPS 2020

## Why it matters

The classic RAG paper formalized combining parametric model memory with a non-parametric external memory.

The original implementation used a sequence-to-sequence generator plus a dense Wikipedia index.

## Key ideas

- external knowledge can be accessed at inference time;
- retrieval and generation can be combined;
- the external index can be updated separately from model weights;
- retrieval quality directly affects downstream performance.

The paper reported state-of-the-art results on several open-domain QA tasks in its original setting and more factual / specific generation than a parametric-only baseline.

## Strategic implication

RAG established the basic external knowledge injection pattern.

The later Agent problem is broader:

When should retrieval happen? What representation should be retrieved? How much context is enough? How is evidence verified? What should persist after the task?
