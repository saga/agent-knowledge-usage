# Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering

Source: https://arxiv.org/abs/2604.08224
Published: 2026-04-09

## Main thesis

The review explains practical Agent progress as externalization:

- Memory → state across time
- Skills → procedural expertise
- Protocols → interaction structure
- Harness → coordination, sandboxing, evaluation and governance

## Why this matters

It connects otherwise separate engineering lines:

RAG + Memory + Skills + MCP + A2A + Sandbox + Evaluation + Approval

into one systems-level idea:

> The Agent becomes more capable because cognitive burdens are moved into reliable external infrastructure.

This is a useful theoretical frame for Common Agent Library and Agent Platform strategy.
