# Memory in the Age of AI Agents

Source: https://arxiv.org/abs/2512.13564
Publication: 2025

## Main taxonomy

The survey distinguishes agent memory from RAG and context engineering.

It organizes memory by:

Forms:
- token-level
- parametric
- latent

Functions:
- factual
- experiential
- working

Dynamics:
- formation
- retrieval
- evolution

## Strategic implication

Not every vector store is “memory”.

Agent memory needs policies for:

- what to write;
- how to validate;
- when to retrieve;
- when to promote;
- how to compress;
- when to forget;
- how to preserve provenance.
