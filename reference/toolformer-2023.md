# Toolformer: Language Models Can Teach Themselves to Use Tools

Source: https://arxiv.org/abs/2302.04761
Publication: 2023

## Main idea

Toolformer explores learning when and how a model should invoke external tools such as calculation, search, translation and calendars.

## Why it matters

It turns external systems into part of the model's effective capability surface.

The conceptual chain is:

model capability + capability discovery + tool selection + tool execution

This is a useful theoretical bridge toward Tool / MCP / Skill architecture.
