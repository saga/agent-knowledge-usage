# Cognitive Architectures for Language Agents (CoALA)

Source: https://arxiv.org/abs/2309.02427
Publication: 2024

## Why it matters

CoALA provides a cognitive-architecture view of language agents rather than treating them as a single prompt loop.

It explicitly considers working memory, long-term memory, retrieval, reasoning, action space and interaction with the environment.

## Strategic implication

Memory, tools, planning and environment interaction should be treated as architectural primitives, not framework-specific implementation details.
